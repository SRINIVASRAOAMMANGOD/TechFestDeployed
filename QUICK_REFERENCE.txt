 IMPORT ORDER (Follow this sequence!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1. Departments  (no dependencies)
 2. Venues       (no dependencies)
 3. Students     (requires Departments)
 4. Events       (requires Departments + Venues)
 5. Registrations (requires Students + Events)
 6. Winners      (requires Students + Events)
 7. Organizers   (requires Events)

 IMPORTANT RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ✓ First row = column headers (REQUIRED)
 ✓ Headers are case-sensitive
 ✓ Date format: YYYY-MM-DD (e.g., 2025-10-25)
 ✓ Foreign keys: use exact names from database
 ✓ File must be .csv extension
 ✓ Use UTF-8 encoding
